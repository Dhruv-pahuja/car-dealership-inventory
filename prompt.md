# Updated AI Usage Summary

AI assistance was used throughout the project primarily as a learning, planning and debugging tool.

Areas where AI was used:

- Understanding assignment requirements and planning implementation.
- Learning Test-Driven Development (Red → Green → Refactor).
- Setting up the Express backend and MongoDB Atlas.
- Configuring Jest and Supertest for integration testing.
- Designing backend architecture using Models, Services, Controllers and Routes.
- Reviewing API design and response structures.
- Debugging authentication, routing and MongoDB issues.
- Planning JWT authentication and role-based authorization.
- Reviewing implementation decisions and suggesting refactoring opportunities.
- Planning frontend architecture and API integration.

All generated suggestions were reviewed, adapted and integrated into the project during development. AI was used as a development assistant for learning, code review, debugging and implementation guidance rather than as a direct replacement for software development.
